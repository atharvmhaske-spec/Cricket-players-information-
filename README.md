# 🏏 Cricket Players Information Android App

An Android application that provides detailed information about cricket players, including their profile, team, career, and performance. The app also includes a **Voice/Text-to-Speech feature 🔊** that reads player information aloud.

## 📱 Features

* 🏏 Cricket Player Profiles
* 👤 Player Personal Information
* 🌍 Country and Team Details
* 🏆 Career Records
* 🔍 Search Players
* 🔊 Voice Player Information
* 📱 Simple and User-Friendly UI


## 🛠️ Technologies Used

* 📱 Android Studio
* ☕ Java
* 🎨 XML
* 🔊 Android Text-to-Speech (TTS)


## 🎯 Project Objective

The objective of this project is to develop an interactive Android application that allows users to easily access cricket player information and listen to the information using voice technology.

## 🚀 How to Run

1. Install **Android Studio**.
2. Clone this repository.
3. Open the project in Android Studio.
4. Allow Gradle to complete synchronization.
5. Connect an Android device or start an Android Emulator.
6. Click **Run ▶️**.
7. Select a player and use the **🔊 Speak** button to hear the information.
